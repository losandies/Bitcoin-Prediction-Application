# Bitcoin Next-Day Direction Predictor

A machine learning app that predicts Bitcoin’s next-day price direction using historical market data and a Random Forest classifier. An interactive Streamlit dashboard lets you explore prices, predictions, and model performance.

## Demo

[Watch the demo](https://github.com/user-attachments/assets/5f05507f-fed8-4034-a944-afcd546311f8)

## Features

- **Next-day prediction:** Displays UP or DOWN/UNCHANGED with an estimated probability of an increase.
- **Price history:** Charts historical Bitcoin closing prices.
- **Historical direction:** Shows how often the following day closed higher or stayed flat/fell.
- **Model evaluation:** Compares test accuracy with a majority-class baseline and displays a confusion matrix.
- **Past predictions:** Select a historical date to compare the model’s prediction with the actual outcome. Training-period examples are labeled.

## How it works

The model uses four features derived from daily market data:

| Feature                 | Description                                               |
| ----------------------- | --------------------------------------------------------- |
| Daily return            | Percentage change in closing price from the previous day  |
| Daily range             | Difference between the high and low, divided by the close |
| Close vs. 7-day average | Closing price relative to its 7-day moving average        |
| 7-day volatility        | Rolling standard deviation of daily returns               |

The target is **UP** when the following day closes higher, and **DOWN/UNCHANGED** otherwise. Data is split chronologically: the oldest 80% of usable rows train the model, and the newest 20% evaluate it. A majority-class baseline provides a reference for interpreting accuracy.

Training uses a Random Forest with 100 trees, a maximum depth of 5, a minimum of 10 samples per leaf, and a fixed random seed of 42. Preprocessing removes the newest CSV row as potentially incomplete and excludes invalid targets and feature windows affected by missing dates or zero trading volume.

## Getting started

You’ll need Python 3 and pip. Run these commands from the project directory.

### 1. Create and activate a virtual environment

```bash
python3 -m venv .venv
```

**macOS / Linux:**

```bash
source .venv/bin/activate
```

**Windows PowerShell:**

```powershell
.venv\Scripts\Activate.ps1
```

### 2. Install dependencies

```bash
python -m pip install -r requirements.txt
```

### 3. Train the model

```bash
python train_model.py
```

This prints evaluation results and creates `model.joblib`, which the dashboard loads. The generated model is excluded from Git, so this step is required after a fresh clone.

### 4. Start the dashboard

```bash
python -m streamlit run app.py
```

Open **http://localhost:8501** in your browser. Press **Control+C** in the terminal to stop the server.

For future sessions, activate the virtual environment and run the Streamlit command again. Retrain after changing the dataset, features, or training code.

## Dataset

The included dataset, `data/Bitstamp_BTCUSD_d.csv`, contains historical daily Bitstamp BTC/USD prices and trading volume. Its source is [CryptoDataDownload](https://www.CryptoDataDownload.com), as recorded in the CSV header.

The application reads this local CSV. Predictions are relative to the latest completed day in the file and do not automatically update with live prices.

To inspect the dataset and view closing-price, volume, and return charts:

```bash
python explore_data.py
```

## Interpreting the results

The model predicts direction rather than a future price. Test accuracy and the confusion matrix measure performance on the chronological holdout set. Historical examples from the training period do not measure performance on unseen data.

This project is an educational machine learning demonstration. Its predictions are not financial advice or a guarantee of future performance.
